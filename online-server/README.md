# Whyclient relay — protocol 14

Node.js 22+, без внешних npm-зависимостей. Официальный адрес: https://why-client.onrender.com. Это сервис косметики и онлайн-статуса; игровой Minecraft-сервер работает отдельно.

```sh
npm test
node server.mjs
```

PORT=8080, HOST=0.0.0.0. На Render Root Directory = `online-server`. `GET /health` проверяет процесс, `GET /v1/capabilities` сообщает visualVersion:14. Бесплатный экземпляр Render может запускаться после простоя с задержкой.

## Whyclient r9

Два игрока с r9, подключённые по одному адресу Minecraft в одном измерении, видят открытый ClickGUI перед владельцем. Передаются PNG самого окна, координаты курсора и короткий сигнал нажатия. Клиент рисует этот же интерфейс и позу выбирающих рук. Закрытие меню, смена комнаты и TTL удаляют панель. Чат и содержимое Items Edition не передаются.

При включённых общих эффектах передаются Target ESP, Die Effect, Wings, форма Custom Model и состояние Why Drone, включая аварию. Studio-эффекты передают ограниченный пресет: форму, траекторию, количество, размер, радиус, время, glow и два цвета. Player Trails, Waypoints и Why Assistant в этой сборке работают локально. Переключатель общих визуалов находится в окне онлайн клиента.

Меню передаётся при включённом онлайн-сервисе независимо от переключателя общих эффектов. `enabled:false` отключает связь с relay. Сервис не управляет игровыми сущностями, предметами, уроном и блоками.

## Формат и совместимость

`POST /v1/visuals/sync` содержит UUID session/player, SHA-256 room, cursor, state и до 8 событий. Комната вычисляется из адреса Minecraft и измерения. Разные адреса/алиасы создают разные комнаты.

- `state.menu.image`: base64 PNG до 128 KiB бинарных данных; ширина 256–1024, высота 128–768, максимум 786432 пикселя, RGB/RGBA 8 bit.
- `state.cosmetics.model`: форма 0–2, сила .25–1.
- `state.cosmetics.drone`: относительная позиция в пределах 48 блоков, yaw/bank, фаза движения/аварии, размер .6–1.8.
- `impact`: стили 0–5 (Mini TNT, Electric Chains, Black Crystals, Rune Cage, Sonic Bloom, Studio), 450–1500 мс.
- `death_v2`: стили 0–6 (Electricization, Black Hole, Ascension, Voxel Shatter, Soul Ribbons, Supernova, Studio), 650–2500 мс.
- Studio обязателен для impact:5 и death_v2:6; пресет проверяется до сохранения.

Прежние поля и события protocol 11–13 поддерживаются. Ответ старому клиенту исключает изображения, позу нажатия, cosmetics и новые события, не меняя сохранённое состояние современного клиента. Старые `custom_death` сохраняют прежнее значение; новые смерти используют отдельный `death_v2`. Неизвестные поля удаляются.

## Лимиты

До 4 запросов/сек, 8 событий/запрос, 256 событий/комнату. State TTL = 6 сек, события = 3 сек. До 12 участников и 64 событий в современном ответе. Запрос визуалов до 256 KiB; ответ protocol 14 до 1000000 байт, прежний ответ до 64000. Общий бюджет PNG в памяти — 8 MiB base64; он освобождается при закрытии, замене или истечении состояния. Ограничения session/room/IP остаются в коде relay.

UUID, параметры, координаты и изображение окна временно хранятся в памяти. Пароли и токены Minecraft не отправляются. Перезапуск удаляет данные. Для нескольких серверных экземпляров потребуется общее хранилище.

`GET /v1/online` и `POST /v1/presence` считают активные сессии, heartbeat 30 сек, TTL 90 сек. TRUST_PROXY=1 подходит только за прокси, который заменяет X-Forwarded-For и закрывает прямой доступ.

## Проверка

`node --test *.test.mjs`: 14 тестов, включая HTTP двух участников с настоящим PNG меню, курсором, моделью, дроном и Studio; старые версии; некорректные поля; предел ответа, памяти, частоты, TTL и разделение комнат. `v14-fixture.mjs` содержит тестовый PNG интерфейса, не загружает внешние файлы.
